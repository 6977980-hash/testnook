# Phase 6 handoff: SEO layer

Date: 28 Oct 2026. Branch `claude/project-thread-ipw5lv`, merged to `main`.

## What was built

1. **Hub pages**, `content/hubs/<slug>.php` for all 8 hubs (keyboard, mouse,
   controller, screen, audio, camera, benchmark, phone). Each has a 53-60 char
   `seo_title`, 149-160 char `description`, a lede, 500-590 words of guide
   text in five H2 sections ("Which test do you need?", "What the tests can
   find", tips, related), 6 FAQs and `updated`. The guide text links every
   tool in the hub. Now that the files exist, `tn_hub_url()` returns `/<hub>/`
   everywhere: header nav, footer, breadcrumbs, homepage section titles.
   `templates/hub.php` prints "Last updated" from `updated`.
2. **OG images**: `assets/img/og/<slug>.jpg` for all 32 tools and 8 hubs
   (1200x630, 35-50 KB each, 1.7 MB total), generated by
   `bin/make-og-images.py` (Pillow + Inter, reads the catalog through PHP so
   there is one source of truth). Same teal gradient and badge as
   `og-default.jpg`, with a kicker (hub title, or "Testnook hub"), the name and
   the blurb. Re-run after adding a tool or hub and commit the output; the
   theme already picked these up when present (`inc/seo.php`).
3. **IndexNow**, `inc/indexnow.php`:
   - `TN_INDEXNOW_KEY` in `inc/config.php` is set (32 hex chars, public by
     design). `/<key>.txt` is served from `parse_request` like `ads.txt`.
   - `tn_sync_pages()` now fires `tn_after_sync( $created, $drafted )`.
     The listener hashes every content file, compares with the last pinged
     hashes (`tn_indexnow_hashes` option) and submits the changed pages, new
     pages, drafted pages, and the homepage when the catalog changed, to
     `https://api.indexnow.org/indexnow` (non-blocking `wp_remote_post`). The
     first run after this deploy has no stored hashes, so it submits the whole
     site once (45 URLs).
   - Pings are only sent when `wp_get_environment_type()` is `production`
     (the default when `WP_ENVIRONMENT_TYPE` is unset, which is the case on
     Hostinger). Local copies never ping. `tn_indexnow_send` filter can veto.
   - `/wp-admin/?tn_indexnow=all` (admins) resubmits every page.
     `tn_indexnow_last` option records the last submission.
   - Sitemap: core `wp-sitemap.xml` lists 45 URLs (home, 32 tools, 8 hubs,
     4 static pages), and core already adds the `Sitemap:` line to
     `robots.txt`. No change needed.
4. **Meta/schema polish** in `inc/seo.php`: `og:image:width/height/alt`,
   `twitter:title/description/image`; `WebApplication` gains `image`,
   `inLanguage`, `isPartOf`, `breadcrumb`, `dateModified` (from `updated`);
   `CollectionPage` gains `description`, `image`, `inLanguage`,
   `dateModified`, and `ItemList.numberOfItems`; static `WebPage` gains
   `description` and `inLanguage`. `TN_VERSION` bumped to 0.2.0 so the
   content signature changes and the sync (and first IndexNow submission)
   runs on the first request after deploy.
5. Docs: `docs/content-format.md` (hub `updated`, OG script, IndexNow
   section), `README.md` (new files).

## Decisions

- Hubs keep `ads => standard`; the slots are `in-content` (after the tool
  grid, before the guide) and `after-faq`, neither next to anything clickable.
- IndexNow pings on content hashes, not on WordPress post changes, because a
  tool's body/FAQ edit does not change the WordPress post (only the intro is
  stored there). Bing, Yandex, Seznam and Naver share the endpoint; Google
  ignores IndexNow, so Search Console + sitemap stays the Google route.
- The key is committed in `inc/config.php`. It is served publicly by design;
  there is nothing secret about it. Rotate it by changing the constant.
- OG images are committed rather than generated on the server: Hostinger PHP
  has GD but the script needs the Inter font, and 1.7 MB of JPEGs in git is
  cheaper than a runtime dependency.
- No `HowTo`, no ratings, no `SoftwareApplication` (the research decision from
  Phase 1 stands; `WebApplication` is the right subtype for a browser tool).

`content/hubs/<slug>.php`, add an icon to `inc/icons.php`, and check the
header still fits at 1024 px with 9+ hub links (it may need to drop to the
menu earlier).
